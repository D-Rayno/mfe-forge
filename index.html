Production-ready MFE architecture for Vite + React + Module Federation

CLI Reference
🚀

Zero-Config Scaffolding

Generate apps, hosts, packages, and design systems with a single command. Auto-detects ports and registers remotes.

🏗️

Scope-Based Architecture

Organize MFEs by team, product, or domain. Each scope gets its own host with automatic remote discovery.

🔌

Auto-Registration

Hosts automatically discover and register remotes in their scope. No manual vite.config editing needed.

🖥️

Dev Orchestration

Run all MFEs in parallel with a single command. Built-in port management and CORS configuration.

📝

Type Safety

Automatic TypeScript declaration generation and sync across all MFEs in your architecture.

🧪

Testing Built-In

Vitest for unit tests, Playwright for E2E. Cross-MFE testing utilities included.

🎨

Design System

Token-based theming with Tailwind CSS. Storybook integration for component documentation.

🐳

CI/CD Ready

Docker, GitHub Actions, and deployment templates. Production builds optimized for Module Federation.

Quick Start ​

bash
# Install globally
npm install -g mfe-forge

# Create a project
mfe-forge init my-platform
cd my-platform

# Generate MFEs
mfe-forge generate host platform/host
mfe-forge generate app platform/auth
mfe-forge generate app platform/dashboard

# Start developing
bun install
bun dev
